TYNG APP – CLIENT-FRIENDLY FEATURE SUMMARY
Updates from 24 September 2026

COACH

- Create coaching sessions at a specific venue and court.
- See only suitable venues and courts for the selected sport.
- View a live schedule with venue, court, player, date, time and session status.
- Avoid accidental double-booking of the same court and time.
- See venue photos while planning a session.
- Move directly between the different steps while setting up a session.
- Accept or decline a player’s coaching request.
- See the requesting player’s name, photo or initials, and request status.
- Accepted players are added to the Coach’s student list.
- View complete session information, including player, venue, court, date, price and status.
- Add private notes to a session and mark player attendance.
- Open directions to the session venue using Google Maps.
- Receive a clear message when attendance or directions are not yet available.
- Upload, view, replace and remove profile photos, training photos, videos and certificates.
- Submit Government ID, coaching certificate and professional profile photo for verification.
- Save coaching locations, availability, pricing, trial preferences and achievements.
- Return later and see saved profile information again.
- See an accurate profile completion percentage based on completed information, gallery items and verification documents.
- Weekly availability now shows each day and time window clearly, with saved-status feedback and an option to clear selections.
- Session notes now have a cleaner layout, private label, character count and clear saving confirmation.
- Update weekly availability using clearer day-by-day time slots, with confirmation once changes are saved.
- After reaching 100% profile completion, the Coach Dashboard and side menu no longer show unnecessary “Complete Profile” reminders.
- Edit all coaching information from one place: languages, coaching locations, travel distance, session types, equipment, trial options, session arrangements, availability, pricing, achievements and bio.
- Update profile gallery items and verification documents directly from Edit Profile whenever needed.
- See the real number of unread chat messages in the Coach Schedule and open Chat directly from that summary.
- See the real number of active coaching sessions beside My Schedule in the side menu.
- See Coach Insights in a clearer layout, with easier-to-understand performance sections and a direct link to the schedule.
- Update profile information from Coach Insights without being asked to complete an already completed profile.

PLAYER

- Receive an update when a Coach accepts or declines a coaching request.
- Receive an invitation when a Coach accepts the request.
- Coordinate the coaching time with the Coach after acceptance.
- See clearer session information and status updates.

VENUE STAFF

- See Coach session requests in the Venue Dashboard.
- See Coach session requests together with regular booking requests in Bookings.
- Review the requested Coach, player, sport, court, date and time.
- Approve a coaching session directly from the Dashboard or Bookings area.
- Approving a session keeps the selected court reserved and sends the player invitation.
- Approved sessions show the correct confirmed status for the Coach and player.
- Venue staff are the only users who can approve the venue request.

ADMIN

- View a scheduling overview covering Coaches, Venues, Players, session requests, venue partnerships, recent sessions and listed prices.
- View complete Coach profile information from the Admin Coach area.
- Review Coach photos, training media, videos and certificates.
- Open submitted verification documents securely.
- See Coach verification and gallery submission progress more clearly.

APP-WIDE IMPROVEMENTS

- Improved the appearance and consistency of cards, buttons, forms, search, filters, tabs, labels, loading screens and messages.
- Before any live server update, the connection and correct server identity are checked first to keep changes safe and on the right system.
- Improved readability, spacing, colours, shadows, touch feedback and keyboard focus.
- Added friendly fallback displays when a profile photo, venue photo or gallery image is unavailable.
- Improved mobile-safe spacing across Player, Coach, Venue, Admin, sign-in, booking, chat and profile screens.
- Kept existing navigation and actions working as before.
